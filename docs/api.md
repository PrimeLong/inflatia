# API Инфляции: все маршруты

Один и тот же код обработчиков (`api/*.js`) работает в двух местах: функциями Vercel (действующий сайт, до переключения)
и сервером Express в ONREZA Compute (`server/app.js`, список маршрутов — `server/routes.js`). Адреса, методы, тела
запросов, коды ответов и тексты ошибок одинаковы; это проверяют `server/__tests__/app.test.js` (каждый файл `api/*.js` —
маршрут сервера) и `e2e/server.e2e.js` (браузер → сервер без подставных ответов).

Общее для всех маршрутов:

- тело — JSON (`Content-Type: application/json`); `text/plain` с JSON внутри тоже принимается — как у Vercel;
- битый JSON — `400 {"error":"Некорректный JSON"}`; тело больше 4,5 МБ — `413` (у Vercel тот же предел);
- неизвестное действие — `400 {"error":"Неизвестное действие"}`; необработанная ошибка — `500 {"error":"Внутренняя ошибка сервера"}`
  (в журнал — только имя обработчика и текст ошибки, без тела запроса);
- незнакомый адрес `/api/...` — `404 {"error":"Нет такого адреса API"}` (только на сервере ONREZA; Vercel отдавал свою 404);
- ответы API — `Cache-Control: no-store` и заголовки безопасности (`server/headers.js`); CORS нет — страница и API на одном домене;
- ключ входа (`token` или `session` в теле) — из `/api/account` (регистрация, вход, восстановление).

Ограничения частоты — по адресу клиента (`api/_lib/client-ip.js`): на сервере ONREZA — адрес, который записал доверенный
прокси (`TRUST_PROXY_HOPS`, `CLIENT_IP_HEADER`), а не присланный браузером `X-Forwarded-For`.

| Маршрут | Методы | Действия (`action` в теле или `?action=`) | Что делает | Ограничения |
|---|---|---|---|---|
| `/api/account` | POST | `register`, `login`, `recover`, `me`, `update`, `password`, `recovery_new`, `logout`, `export`, `delete`, `card`, `friends`, `friend-add`, `friend-answer`, `friend-cancel`, `friend-remove`, `race-invite`, `race-answer`, `league-names`, `require-rename` (владельцы) | аккаунт: регистрация с согласиями и годом рождения (до 14 лет — подтверждение родителя), вход, восстановление кодом, профиль, смена пароля и ника, «Скачать мои данные» (с записями исследования), «Удалить аккаунт» (с исследованием), друзья, забеги, карточка лиги | регистрация — 5 в час с адреса; вход — 30 в час с адреса и нарастающая блокировка логина (5 неверных паролей → 1 мин, 5, 15, 60 мин, 6 ч); восстановление — 10 в час; заявки в друзья — 30 в час; карточка — 20 в минуту; приглашения на забег — 10 в сутки |
| `/api/solo` | GET, POST | GET: `?playerId&slot`, `?kind=tycoon`; POST: `save`, `delete`, `rename`, `progress`, `link_create`, `link_claim`, `link_status`, `link_cancel`, `link_revoke` | сохранения партий «Мира» и «Своего дела», прогресс обучения (синхронизация устройств), связывание устройств кодом | размер имени, слота и id; связывание — одноразовым кодом со сроком |
| `/api/daily` | GET, POST | GET: `?day&playerId`; POST: результат дня | вызов дня: таблица дня и запись результата | приём только за открытые дни |
| `/api/records` | GET, POST | GET: `?kind&login`; POST: рекорд из профиля | таблица рекордов | запись — только из профиля, не заблокированного |
| `/api/room` | GET, POST | GET: `?id&since&seat&token`, `?list=1`; POST: `create`, `join`, `leave`, `kick`, `submit`, `unsubmit`, `chat`, `set_difficulty`, `report_portfolio` | сетевые комнаты «Мира»: места, ходы ведомств, чат | места закреплены за профилем; чат — фильтр грубых слов |
| `/api/reports` | POST | `send`, `crash`, `filter`, `me`, `list`, `status`, `status-many`, `delete`, `done-all`, `purge-done` | «Сообщить об ошибке», отчёты о сбоях, разбор жалоб владельцами | жалобы — по логину в час и втрое больше с адреса; сбои и фильтр — по адресу в час |
| `/api/events` | POST | событие (`event`), `report` (владельцы) | обезличенные счётчики аналитики; отчёт владельцам | — |
| `/api/research` | GET, POST | GET: `status`; POST: `enroll`, `resume`, `form`, `pretest`, `event`, `answer`, `progress`, `test`, `withdraw`; `export`, `purge` — по ключу исследователя (`X-Research-Token`) | исследование (своя таблица `inflatia_research`). **Закрыто**: `STUDY_STATUS = 'draft'` — всё, кроме `status`, отвечает 403 | запись — только с аккаунтом и годом рождения 18+; 300 записей в сутки; ответы — только после «начал урок» и по порядку заданий |
| `/api/health` | GET | `?proxy=1` — форма заголовков прокси (без адресов) | отвечает ли база, где работает сервер | — |

Переменные окружения, которые читает сервер, — `docs/onreza.md`, «Переменные окружения».
